BIBLIOTECA SVG AVATAR - PROTÓTIPO VETORIAL ORIGINAL

Cada SVG tem canvas 1024 x 1024, fundo transparente e formas vetoriais, sem imagens embutidas.
Importação no Figma: arraste os SVGs para uma página e alinhe todos pelo canto superior esquerdo em uma mesma moldura 1024 x 1024.
Ordem sugerida: corpo > calça > sapatos > camisa > rosto > olhos > expressão > detalhe facial > cabelo > brincos > óculos > cachecol > chapéu.
Os SVGs utilizam cores de fallback com CSS var(--skin), var(--hair) e fill editável. No Figma edite preenchimentos das formas para alterar cores.
As amostras de cores são peças de catálogo, não camadas para empilhar no personagem.
ATENÇÃO: recriação vetorial estilizada inspirada na referência, NÃO vetorização perfeita pixel-a-pixel. Alguns itens estão simplificados.
